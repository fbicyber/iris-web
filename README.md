# IRIS

[![License: LGPL v3](https://img.shields.io/badge/License-LGPL_v3-blue.svg)](./LICENSE.txt)   
Iris is a web collaborative platform aiming to help incident responders sharing technical details during investigations. 

## Differences between FBI Cyber's Iris and DFIR-Iris (Coming Soon)
Most of the key changes are in the Timeline, where the events are displayed in a tabular format to streamline investigators' workflow of tracking events. 
More details of the differences are coming soon!
